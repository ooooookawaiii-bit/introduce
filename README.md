# 🎀 김나비의 자기소개 웹페이지 (Introduce) 💕

웹 프로그래밍 단계별 자기소개 페이지 및 반응형 목차 포트폴리오입니다.

---

## 📂 파일 및 폴더 구조

- **[index.html](index.html)**: 3단계 페이지로 바로 이동할 수 있는 반응형 목차 페이지 (Table of Contents)
- **1-html.html**: STEP 01 - 시맨틱 태그 기반 HTML 기초 자기소개
- **2-css.html**: STEP 02 - 지라이케이 & 양산형 고딕 핑크 CSS 프릴/레이스 스타일링
- **3-js.html**: STEP 03 (FINAL) - 다크모드, 1:1 대화 DM 모달, 실시간 인터랙션 완성본
- **profile.jpg**: 프로필 이미지
- **introduce/**: `index.html` 내 링크 경로 호환을 위한 서브 디렉토리

---

## ✨ 주요 기능 및 특징

1. **단계별 학습 구조**: HTML 기본 마크업부터 CSS 디자인, JavaScript 동적 기능까지 단계별 확인 가능
2. **반응형 웹 디자인**: 모바일 및 데스크톱 환경 모두에 최적화된 레이아웃
3. **디테일한 테마 시스템**: 핑크 모드 및 고딕 다크 모드 테마 전환 지원
4. **인터랙티브 기능**: 1:1 친구 대화 DM 모달 및 터치/클릭 파티클 효과
